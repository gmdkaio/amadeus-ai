# Amadeus

Fine-tuning Qwen 2.5 with LoRA to take on a specific character's voice and speech patterns while keeping the base model's general knowledge, then running it fully local on a consumer GPU. It's based on Amadeus from Steins;Gate 0, the AI that recreates a person's mind from their memories, and the target persona is Kurisu Makise from Steins;Gate, trained on dialogue extracted from the visual novels, with a fine-tuned GPT-SoVITS model for speech.
